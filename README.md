# Sunny Side Search

Поиск по выделенному тексту в один клик: выделяете слово или фразу – над ним появляется аккуратная панель с вашими поисковиками.
Search any selected text in one click: a sleek bar with your own search engines appears right above the selection.

**Chrome Web Store:** https://chromewebstore.google.com/detail/fhcglajlaohclaigglgplpoplagdcefb

## Версия 1.3.0

- Поиск по картинке: правый щелчок по изображению → «Найти похожие картинки» → Google Lens, Яндекс Картинки или TinEye.
- Окно на панели браузера можно показывать списком: Внешний вид → «Окно на панели браузера» → «Вид: Список».
- Пункт «Открыть все» в папках контекстного меню отключается: Поведение → «„Открыть все“ в папках».

## Установка из файла

1. Скачайте файл: [Sunny Side Search 1.3.0.crx](https://github.com/DmitryN71/Sunny-Side-Search/raw/refs/heads/main/Sunny%20Side%20Search%201.3.0.crx).
2. Откройте страницу расширений: `chrome://extensions` (в Brave – `brave://extensions`) и включите «Режим разработчика».
3. Перетащите скачанный файл в окно со списком расширений.

Файл подписан Chrome Web Store и имеет тот же ID, что и версия в магазине: установленное расширение просто обновится, а следующие версии придут из магазина автоматически.

## Installing from the file

Download [Sunny Side Search 1.3.0.crx](https://github.com/DmitryN71/Sunny-Side-Search/raw/refs/heads/main/Sunny%20Side%20Search%201.3.0.crx), open `chrome://extensions`, turn on Developer mode and drop the file onto the page. The file is signed by the Chrome Web Store and has the same ID as the store version, so later updates arrive from the store as usual.
